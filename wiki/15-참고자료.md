# 15. 참고 자료

## 공식 매뉴얼

로컬 시스템에서 `man` 으로 바로 열 수 있는 자료들. 평가자가 확인할 때도 이것이 "권위 있는" 소스입니다.

### 시스템 콜 (section 2)

```sh
man 2 fork          # 프로세스 생성
man 2 execve        # 프로그램 교체
man 2 wait          # 자식 수거 기본
man 2 waitpid       # 세밀한 자식 수거
man 2 pipe          # 파이프 생성
man 2 dup           # fd 복제
man 2 open          # 파일 열기
man 2 close
man 2 read
man 2 write
man 2 access
man 2 signal        # (레거시) 시그널 설치
man 2 sigaction     # 시그널 설치
man 2 kill          # 시그널 송신
man 2 chdir
man 2 stat
```

### 라이브러리 함수 (section 3)

```sh
man 3 readline      # GNU Readline
man 3 termios       # 터미널 속성
man 3 tputs         # termcap 출력
man 3 perror        # 에러 메시지 출력
man 3 strerror
```

### 개요 (section 7)

섹션 7은 **프로토콜·규약 설명**. 특히 유용:

```sh
man 7 signal         # 모든 시그널, 기본 동작, 규칙 정리
man 7 signal-safety  # async-signal-safe 함수 목록
man 7 pipe           # 파이프의 EOF 규칙 등
```

## bash 매뉴얼

```sh
man bash                      # 매우 길지만 절대적 레퍼런스
man bash | less +/'SHELL GRAMMAR'
man bash | less +/'Redirection'
man bash | less +/'Signal Handling'
```

특히 "SHELL GRAMMAR", "Redirection", "Parameter Expansion" 섹션이 중요.

온라인:
- https://www.gnu.org/software/bash/manual/bash.html

## POSIX Shell Specification

**공식 POSIX 스펙**은 bash 매뉴얼보다 간결하고 엄격합니다. 애매한 동작의 근거를 찾을 때 유용.

- [Shell Command Language](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html)
- [XSH (System Interfaces)](https://pubs.opengroup.org/onlinepubs/9699919799/functions/contents.html) — 시스템 콜 명세
- [XCU (Utilities)](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/contents.html) — 빌트인·명령 스펙 (cd, echo, exit 등)

## 도구

### 디버깅
- `gdb` — 표준 디버거
  ```sh
  gdb ./minishell
  (gdb) break main
  (gdb) run
  (gdb) backtrace
  ```
- `lldb` — macOS 에서 자주 씀
- `strace` (리눅스) / `dtruss` (macOS) — 시스템 콜 추적
  ```sh
  strace -f -e trace=fork,execve,pipe,dup2 ./minishell
  ```

### 메모리 검증
- `valgrind --leak-check=full` — 리눅스
- AddressSanitizer (`-fsanitize=address`) — 컴파일 시 통합

### 테스트 프레임워크 (선택)
- [minishell_tester](https://github.com/zstenger93/42_minishell_tester) — 42 커뮤니티 공용 테스트 모음

- 직접 bash 와 diff 를 떠보는 쉘 스크립트도 빠르게 만들 수 있음.

## 빠른 트러블슈팅 가이드

### "프롬프트에서 Ctrl-C 가 이상해요"
- 핸들러 설치 확인
- `rl_on_new_line` / `rl_replace_line` / `rl_redisplay` 호출 순서
- `SA_RESTART` 플래그

### "자식에서 Ctrl-C 가 안 먹혀요"
- `restore_signal()` 을 execve 직전 호출했는지

### "파이프가 데드락 걸려요"
- 부모에서 pipe 양쪽 close 했는지
- 자식에서 dup2 한 원본 close 했는지

### "히어독이 이상하게 종료돼요"
- heredoc 수집을 `eval()` 전에 미리 했는지
- 자식 프로세스에서 수집하는 경우 `init_heredoc_signal()`

### "valgrind 가 leak 수백 개 말해요"
- readline suppression 파일 적용했는지
- 토큰 리스트·AST·해시맵 해제 누락 있는지

### "`>` 리다이렉션이 안 돼요"
- `open` 플래그: `O_WRONLY | O_CREAT | O_TRUNC`, 모드 `0644`
- `dup2(fd, STDOUT_FILENO)` 후 원본 `close(fd)`

### "`$?` 가 이상해요"
- 외부 명령: `WIFEXITED` ? `WEXITSTATUS` : `128 + WTERMSIG`
- 빌트인: 빌트인 함수 리턴값 그대로
- 파이프라인: 가장 오른쪽 명령 기준
