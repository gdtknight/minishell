# 01. 프로젝트 개요

42 minishell은 bash와 유사하게 동작하는 간단한 셸을 C로 작성하는 프로젝트입니다. 서브젝트 버전 v10.0 기준입니다. 이 문서는 서브젝트의 요구사항을 항목별로 정리하고, 구현 시 꼭 기억해야 할 제약을 짚습니다.

## 프로그램이 갖춰야 하는 기능

서브젝트 Chapter IV "Mandatory part"에서 요구하는 항목입니다.

### 실행 환경
- 대화형 셸로 동작해야 하며, 명령을 기다릴 때 **프롬프트를 출력**.
- **명령 히스토리**가 유지되어야 함(`up arrow`로 이전 명령 불러오기).
- **PATH 변수**를 이용해 실행 파일을 찾고, 절대/상대 경로도 지원.

### 인용과 메타 문자
- **`\`**(백슬래시) 및 **`;`**(세미콜론)은 mandatory 파트에서 **해석하지 않음**(구현하지 말라는 뜻).
- **`'`**(작은따옴표): 그 안의 메타 문자를 전혀 해석하지 않음.
- **`"`**(큰따옴표): 그 안의 메타 문자를 해석하지 않되, **`$`는 예외**(변수 확장 수행).

### 리다이렉션
| 기호 | 의미 |
|------|------|
| `<`  | 입력 리다이렉션 |
| `>`  | 출력 리다이렉션 (덮어쓰기) |
| `>>` | 출력 리다이렉션 (이어쓰기) |
| `<<` | heredoc: 지정한 구분자를 만날 때까지 입력을 읽음. **히스토리에 남기지 않아도 됨** |

### 파이프
- `|`로 왼쪽 명령의 표준 출력을 오른쪽 명령의 표준 입력에 연결.

### 변수 확장
- `$이름` 형태는 환경 변수 값으로 치환.
- `$?`는 **가장 최근에 종료된 포그라운드 파이프라인의 종료 상태**로 치환.

### 시그널 (ctrl 키 조합)
- **ctrl-C**: 새 줄에서 새 프롬프트 표시.
- **ctrl-D**: 셸 종료 (EOF).
- **ctrl-\\**: 아무 일도 하지 않음.

### 빌트인 커맨드 (7개)
1. `echo` (`-n` 옵션 포함)
2. `cd` (상대/절대 경로만)
3. `pwd` (옵션 없음)
4. `export` (옵션 없음)
5. `unset` (옵션 없음)
6. `env` (옵션·인자 없음)
7. `exit` (옵션 없음)

> 서브젝트가 명시하지 않은 옵션·기능은 **구현하지 말 것**("Anything that is not asked is not required").

## 보너스 파트

Chapter VI에서 요구하는 보너스 기능입니다. Mandatory가 완벽히 통과해야만 채점됩니다.

- **`&&`** 과 **`||`** 우선순위 처리 (괄호 `(`, `)` 지원).
- **와일드카드 `*`** 는 현재 작업 디렉터리(cwd) 기준으로 동작.

보너스 파일은 반드시 **`_bonus.c`** / **`_bonus.h`** 접미사를 쓰고, Makefile에 **`bonus` 룰**을 따로 둬야 합니다. Mandatory와 bonus는 분리 평가됩니다.

## 허용된 외부 함수

**이 목록 밖에 있는 함수를 쓰면 0점**입니다. libft는 예외입니다.

### Readline 관련

### 기본 입출력 / 메모리
`printf`, `malloc`, `free`, `write`, `read`

### 프로세스 제어
`fork`, `wait`, `waitpid`, `wait3`, `wait4`, `execve`, `exit`, `kill`

### 시그널
`signal`, `sigaction`, `sigemptyset`, `sigaddset`

### 파일 / 디렉터리
`access`, `open`, `close`, `unlink`, `stat`, `lstat`, `fstat`, `opendir`, `readdir`, `closedir`, `getcwd`, `chdir`

### 파일 디스크립터 조작
`dup`, `dup2`, `pipe`

### 환경·에러
`getenv`, `strerror`, `perror`

### 터미널
`isatty`, `ttyname`, `ttyslot`, `ioctl`, `tcsetattr`, `tcgetattr`, `tgetent`, `tgetflag`, `tgetnum`, `tgetstr`, `tgoto`, `tputs`

### 실수로 쓰기 쉬운 금지 함수 예시

이 목록에 **없는** 함수 중 많이들 실수로 쓰는 것:

- `strcmp`, `strncmp`, `strlen`, `strdup` — libft의 `ft_*` 버전을 사용.
- `fprintf`, `sprintf`, `snprintf` — `printf` + `write` 조합이나 libft `ft_putstr_fd`.
- `memset`, `memcpy`, `bzero` — libft `ft_memset`, `ft_memcpy`, `ft_bzero`.
- `atoi`, `itoa` — libft `ft_atoi`, `ft_itoa`.
- `gets`, `fgets` — 본인이 만든 `get_next_line` 사용.
- `system()` — 절대 사용 금지(채점자 입장에서 레드카드).

## 전역 변수 규칙

서브젝트의 가장 까다로운 조항 중 하나입니다.

> **Use at most one global variable to indicate a received signal.**
>
> 이 전역 변수는 **시그널 번호만** 저장해야 하며, 메인 데이터 구조에 접근하거나 추가 정보를 제공하면 안 됨. Norm에서 쓰는 타입의 구조체를 전역 범위에 두는 것은 **금지**.

즉 다음과 같은 패턴만 허용됩니다.

```c
volatile sig_atomic_t	g_signal = 0;

void	sigint_handler(int signo)
{
    g_signal = signo;
}
```

다음은 **금지**입니다:

```c
t_shell		g_shell;         /* 구조체 전역 — 금지 */
int		g_pipe_fds[2];       /* 배열이라도 시그널 외 용도는 금지 */
```

시그널 핸들러와 메인 루프 사이의 통신은 **시그널 번호 하나만으로** 해결해야 합니다. 해결 패턴은 [06. 시그널 처리](06-시그널-처리)에서 다룹니다.

## 메모리 누수 정책

> 힙에 할당한 모든 메모리는 **적절한 시점에 반드시 해제**되어야 함. 메모리 누수는 허용되지 않음.

단, `readline()` 내부에서 발생하는 누수는 **예외**로 인정됩니다. 하지만 **본인이 작성한 코드**에서 누수가 생기면 감점입니다.

검사 방법은 보통:

```sh
valgrind --leak-check=full --show-leak-kinds=all \
         --suppressions=readline.supp ./minishell
```

readline 누수를 무시하기 위한 suppression 파일을 함께 쓰는 것이 일반적입니다. 자세한 내용은 [14. 메모리 관리](14-메모리-관리).

## 크래시 금지

> 세그폴트, 버스 에러, 더블 프리 같은 비정상 종료는 평가에서 **0점**. "undefined behavior"에 한해서만 예외.

입력이 아무리 이상해도 셸이 죽으면 안 됩니다. 대표적으로 주의할 입력:

- 빈 입력, 공백만 있는 입력
- 끝나지 않은 따옴표 — 서브젝트가 "unclosed quotes는 해석하지 않아도 된다"고 허용하지만, 크래시는 안 됨
- `|`, `<`, `>` 같은 연산자만 있는 입력
- 매우 긴 입력
- 환경 변수가 없는 상태(`env -i ./minishell`)

## Makefile 요구사항

- 필수 룰: `$(NAME)`, `all`, `clean`, `fclean`, `re`
- 컴파일러는 `cc`, 플래그는 `-Wall -Wextra -Werror`
- **불필요한 재링크 금지**(의존성 올바르게 구성)
- 보너스 빌드는 `bonus` 룰로 분리
- libft를 쓴다면 `libft/` 디렉터리에 복사하고, 프로젝트 Makefile이 libft Makefile을 호출해서 컴파일하도록 구성
